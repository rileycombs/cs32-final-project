# cs32-final-project
CS32 Final Project with Leah and Riley

## Our Plan
Leah and Riley intend to make a "Guess Who" came that a user can play with a computer. The computer will be provided with a set of people who have shared traits, but their set of traits will be unique to them. The computer will make a guess after the user answers questions that it answers.

## How to Run the Program
1. Open python!
2. Download or clone this repository.
3. Open a terminal and navigate to the project folder.
4. Run the program with: python3 FPStatus.py
5. Follow the prompts in the terminal.
6. The program will guess your character based on your answers.
